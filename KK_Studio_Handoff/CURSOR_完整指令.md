# Cursor 整合指令（請全文貼到 Agent 模式）

你現在正在操作本機已開啟的網站專案。請只以此工作區為對象，不需要知道也不要猜測任何正式網站網址。這是測試版工作區；禁止自動 push、發布或部署。

## 一、先讀取本機素材
使用工作區內的 `KK_Studio_Handoff/` 資料夾。請先列出並確認下列檔案存在：
- `KK_Studio_Handoff/README.md`
- `KK_Studio_Handoff/reference/prototype.html`
- `KK_Studio_Handoff/reference/prototype.css`
- `KK_Studio_Handoff/reference/prototype.js`
- `KK_Studio_Handoff/reference/HOME_LAYOUT_SPEC.md`
- `KK_Studio_Handoff/reference/ANIMATION_PLAN.md`
- `KK_Studio_Handoff/assets/phonemes/` 內的 `.svg` 示例圖與動畫

若找不到上述資料夾，先在工作區內搜尋 `CURSOR_完整指令.md` 所在路徑，使用實際找到的路徑；若仍找不到，停止並告知我，不要自行重畫代替。

請先閱讀所有說明文件與示例，確認 SVG 是否能以瀏覽器直接載入。`reference/prototype.*` 只能當視覺排版概念，不可將它當成正式站的來源或直接整頁覆蓋。

## 二、先盤點現有專案，不要直接重寫
請檢查工作區內的 package / 路由 / 畫面元件 / 音標資料來源 / 發音播放 / 課程 / 練習頁，並先摘要回報：
1. 目前首頁或圖表頁的入口元件與路由。
2. 目前音標的完整列表、總數，以及 KK/IPA 的對照方式。
3. 哪些舊功能與儲存資料需要原樣保留。
4. 將修改哪些檔案；是否有與既存元件衝突。

**嚴禁直接用素材包中的示例音標資料覆蓋現有資料。** 特別注意不同教材的 KK/IPA 對照、長音記號、捲舌音、/eɪ/ 與 /oʊ/ 分類、以及字體符號差異，須以原專案採用的音標系統為準。素材包中的圖是示範而非語音學校訂版本。

## 三、首頁：音標總表（不是地圖）
視覺風格為現代編輯式教育網站：大量留白、淡藍、奶油白、柔和鼠尾草綠、細邊框、少量幾何圖像、專業而有童趣。不複製任何其他網站的原創插圖或版面。

首頁包含：
- 簡潔 Hero：「KK 音標互動學習」與一句短說明；不要讓 Hero 太高而擠掉圖表。
- 母音 Vowels：保留原站完整音標，依目前系統合適的分類整理。可以視覺輔助前/中/後與舌位高度，但若分類有歧義，不要擅自改變其母音清單。
- 半母音 Semi-vowels：維持原站的歸屬與數量。
- 子音 Consonants：可在原清濁配對旁補充發音部位與方式，但切勿丟掉既有音標。
- 單個音標卡要能點入原本對應的發音課程。
- KK / IPA 切換若原站已支援就沿用；若沒有，先顯示並列資訊而非偽造切換功能。
- 手機閱讀優先，允許表格區塊內橫向捲動，但整個頁面不得橫溢出。

視覺參考 `reference/prototype.html` 與 `.css`，請重新整理成符合專案框架的元件與樣式，不要直接貼入內聯 demo script。

## 四、發音教室詳細頁
每個音標都以同一套版型顯示：
- 音標主標題（KK 與 IPA）
- 靜態口型與舌位教學圖
- 3–5 秒示意動畫
- 說明欄：嘴唇、舌位、氣流、清濁/聲帶狀態
- 原本例字、音檔/語音播放、進階練習、前後音標導覽
- 動畫播放/暫停/重播；若使用 `<img>` 載入 SVG 無法控制暫停，改採符合目前框架的嵌入播放器，但需避免任意注入不可信 SVG
- 適用 `prefers-reduced-motion` 的靜態替代模式

## 五、如何使用素材圖與動畫
`assets/phonemes/` 中包含以下 5 個代表音的成對示例：`i`, `ae`, `u`, `p`, `sh`。
- `*_still.svg` 是靜態概念圖。
- `*_motion.svg` 是 4 秒循環 SVG 示意動畫。
- 檔名不要因為音標特殊字元造成 URL 路徑問題；用 `ae`, `sh` 等 ASCII ID。
- 請將素材**複製**到專案既有的公開靜態素材目錄，或依框架方式 import；不要把正式頁面用的 URL 指向 `KK_Studio_Handoff` 內不會部署的位置。
- 建立依現有 phoneme id 對應資產路徑的單一 mapping，不要假設原站一定使用示例 ID。
- 如果圖片/動畫缺漏，顯示易讀的靜態卡片和「動畫準備中」，不可讓頁面崩潰。
- 這五個示例是**視覺風格與動態節奏示範，不代表已校訂的實際口腔解剖動畫**。上線前須核對每個發音舌位、嘴型與動作；未核對時標記示意，不應宣稱精確。
