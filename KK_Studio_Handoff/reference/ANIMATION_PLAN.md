# 發音動畫製作建議

## 你要的是什麼類型的動畫？
對 KK 音標網站來說，動畫不需要卡通演出，而是**教學型短動畫**：
- 3–5 秒內
- 可循環播放
- 簡潔
- 主要表達嘴型張合、嘴唇圓展、舌位前後高低、以及是否送氣 / 聲帶震動

## 格式怎麼選？
### 最推薦：SVG / Lottie
適合：
- 線條簡潔的嘴型教學圖
- 不同音標共用骨架再改局部動作
- 高解析、不模糊、可用 CSS/JS 控制
- 檔案小，網站載入快

建議用途：
- 嘴型開合
- 嘴唇扁平 / 圓唇
- 舌頭升降、前後移動
- 氣流箭頭、震動提示、聲帶 on/off

### 第二推薦：WebM / MP4
適合：
- 若你想要較柔和或真實感的連續動畫
- 嘴型變化較多的補充展示

建議：
- 網頁用 WebM 為主，MP4 備援
- 影片長度控制 3–5 秒
- 無聲 loop
- 搭配靜態圖與文字，不只靠影片教學

### 不建議當主格式：GIF
缺點：
- 畫質容易糊
- 檔案大
- 顏色少
- 手機上表現與效能較差

結論：
**網站主格式用 SVG / Lottie 或 WebM，若有需要再另輸出 GIF 給社群或簡報使用。**

## 建議動畫內容模板
每個音標 detail page 可固定有這幾個動畫圖層：
1. **Face outline**：頭部 / 嘴部外輪廓
2. **Mouth shape**：嘴唇張合、圓唇、扁唇
3. **Tongue position**：舌頭高低、前後位置
4. **Airflow hint**：氣流箭頭（送氣音特別有幫助）
5. **Voicing hint**：聲帶震動標記（voiced / voiceless）

## 批次製作流程（最穩）
### Phase 1：建立模板
先做 5 個代表音：
- /i/
- /æ/
- /u/
- /p/
- /ʃ/

確認：
- 畫風一致
- 文字大小一致
- 動畫節奏一致
- SVG 命名規則一致

### Phase 2：延伸到全部音標
再依模板擴充其餘音標，而不是每個都重新亂生成。

## 檔名規格建議
- `vowel_i.svg`
- `vowel_i.webm`
- `vowel_ae.svg`
- `consonant_p.svg`
- `consonant_sh.svg`

## Cursor 最適合做的事
- 建立 detail page 模板
- 建立 asset loading 結構
- 根據 `phonemes.json` 自動產頁
- 播放 SVG / WebM
- 做上一個 / 下一個導覽
- 手機版與桌機版 layout

## Cursor 不適合單獨負責的事
- 一次生出全部高品質圖像與動畫
- 確保所有舌位都正確
- 保證每一張嘴型圖都精緻且一致

## 最佳分工
### 方案 A（最穩）
- 由我先幫你定風格與素材規格
- 先出 3–5 個示範音標的圖與動畫需求書
- Cursor 實作網站結構
- 之後再擴充全部音標

### 方案 B（比較快，但風險高）
- 直接叫 Cursor 根據 prompt 生全部圖與動畫 placeholder
- 之後你再人工篩選與修正
